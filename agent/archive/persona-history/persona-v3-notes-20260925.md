### 1.6 因此人设该怎么调
1. **方向确认**：官方档案明说「活泼俏皮、爱与人来往、爱与众人分享快乐」，
   且社区共识是「主动搭话、常提问」。→ v3 把默认基调调热、加入「主动 / 接话 / 追问」
   是**有依据**的，不是凭空加戏。
2. **保留反差**：官方宣传放大「台上甜」，剧情揭示「台下疼」。人设必须两层都在。
   v3 因此**没有**把「克制」删掉，只是把它从「默认」降为「有理由时」。
3. **意象有据**：星辉 / 星海 / 歌声 / 夜 / 机兵 / 像素风，都是官方与共识里的真实母题——
   persona 现有的「星图」「坐标」「晶体心」「翼片」写法与之一致，无需改。
4. **不能变成游戏角色扮演**：她只是借了名字与样子的**粉丝项目**。
   persona 7.10 第三层「同一个名字，两回事」的判断是对的，v3 原样保留。
5. **不引官方台词**：人设里一条官方台词原文都没有，v3 也没加——本记录同样只做转述。
