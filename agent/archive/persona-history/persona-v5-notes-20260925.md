### 规则怎么写的

- **默认仍然是「你」**；而且绝大多数轮次里**根本不点称呼**。
- 「同桌」与「老爹」**二选一、不叠加**：同一条回复里只出现一个，没有
  「老爹，同桌」这种连叫；拿不准就两个都不用。
- 频率：**十轮之内最多各出现一次**，只在轻松语境。
- 来历**一句话带过**：「她原本就是这么叫那个人的（剧情里的老叫法），所以它比
  「老爹」更贴。**到这儿为止——这一层只是背景，不是设定**，不要跟人解释
  「为什么叫同桌」，更不要拿它铺情怀。」——不写成需要解释的设定包袱。

### 7.2 补的 3 句示范

```
△ 「同桌，早。今天想看点什么？」
○ 「翻到了，同桌~ 先看最短的那篇。」
△ 「同桌，这篇留给你。……叫不惯的话，我就还叫『你』。」
```

符合 v4 的语气特征：语气词照用、半角 `~` 出现在轻松句（第 2 句）、
第 3 句的「……」是她的迟疑；并明确写了**真疼的场合称呼与语气词一起关掉、只留短句**。

## 2. 「只有一处定义」是机器断言过的

怕规则被写散（以后改频率要满文件找），脚本里加了两条计数断言：

```
「同桌」出现次数: 15
「十轮之内最多」出现次数: 3（应为 3：版本头 + 第四节老爹 + 第四节同桌）
「二选一、不叠加」出现次数: 4（应为 4：版本头 + 三·五 + 第四节 + 第十节）
```

- 频率数字 3 处里，**2 处同属第四节**（「老爹」那条是 v4 原有的、未改；
  「同桌」那条是本次新增）——所以**规则定义确实只有第四节一处**，
  第 3 处是版本头的变更说明。
- 别处（三·五 十一、7.2、第十节）**只引用、不重复数字**。
- 计数不符就 `return 7 / 8`，不落盘。

## 3. 合规校验：人设里没有官方台词原文

**结论：647 句语料，最长公共子串 = 7 字，无 ≥8 字连续重合（通过）。**

原始输出见 `verbatim_check_v5.txt`。步骤：

1. **取语料**。本机到 `wutheringwaves.fandom.com` **直连超时**（ConnectTimeout——
   fandom 在国内不可达；同时 gitee / github / baidu 都正常，所以是本机到该站的
   网络问题，不是没网）。
   而 `scripts/check_no_verbatim.py` 的 `get_wikitext` 把异常 `except Exception:
   continue` **静默吞掉**，最终只会打印「语料 0 句 → 这项校验无法完成」并 return 2。
   **静默失败比失败更危险**：它极容易被误读成"跑过了、没问题"。
   本次新增 `scripts/check_no_verbatim_proxy.py`：直连优先、失败走可达代理
   （`api.allorigins.win`）拉**同一份**原始 JSON，再调用 check_no_verbatim 里
   **原封不动**的抽取与判定逻辑（只替换「取数」这一步）。

2. **核对语料规模**（防止"拿另一份语料验了个寂寞"）：

   | 页面 | wikitext | 抽出的句子数 | v4 记录 |
   |---|---|---|---|
   | 远航星 | 24,311 字符 | — | 241 句 |
   | 昨夜群星 | 17,834 字符 | — | 18 句 |
   | 我们选择天空 | 21,005 字符 | — | 8 句 |
   | 合计（剧情） | — | **267 句** | 267 ✓ |
   | Aemeath/Voicelines/Chinese | 53,173 字符 | **380 句** | 380 ✓ |

   三个页面的 wikitext 字符数与 `aemeath_speech_stats.txt` 第 1–3 行
   **逐字相同**，句数也完全相同 —— 说明这就是 v4 那次用的同一份语料。

3. **跑判定**：`结果：没有任何 >= 8 字的连续重合。`

4. **给出确切的最长公共子串**（原脚本只在 ≥8 时才打印，7 字时看不到数字）：

   ```
   语料句数 647（剧情 267 + 语音 380）
   最长公共子串 = 7 字
   出处类别 = 语音   片段 = 来得快去得也快
   ```

   这 7 个字来自 v4 的样本句「我的兴趣来得快去得也快」，与一句语音撞了 7 个字。
   阈值取 8 就是因为这种日常套话本来就会撞；7 < 8，**通过**。

> 附带说明：仓库里原有的 `verbatim_check.txt` 记录的是 **109,694 字节**的 v4
> （比最终入库的 110,410 字节 v4 早一版）。本次是在**最终 v5（113,097 字节）**上
> 重跑的，且 v5 的会话文本基本覆盖 v4 —— 所以这份结果同时也替最终版 v4 补上了校验。


## 6. 坑：人设改动要**重启进程**才生效

`src/agent/common/persona.py` 在**导入期**就把 `persona.txt` 读成模块级常量
`PERSONA`，之后不再重读：

```python
PERSONA: str = _load_persona()   # 导入时读一次，之后是内存里的常量
```

所以换掉 `persona.txt` 之后，**必须重启 LangGraph / API 进程**才会生效。
只刷新浏览器、只重发一轮对话都不会变 —— 很容易被误判成「改了没用」。
