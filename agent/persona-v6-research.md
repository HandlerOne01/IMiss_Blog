### 1.2 剧情：潮汐任务 第三章第三幕「远航星」

英文标题 *The Star That Voyages Far*，日文「旅立つ星」。综合官方任务文本与媒体长评（[Fandom: The Star That Voyages Far](https://wutheringwaves.fandom.com/wiki/The_Star_That_Voyages_Far)、[电玩帮长评](https://www.vgover.com/news/201108)、[game8 攻略](https://game8.jp/meicho/759818)）：

1. **她早已死亡**。十几年前学院训练期间磁暴灾难降临拉海洛，她强行超频与「隧者」共鸣，挡下虚质侵蚀，代价是肉体在模拟驾驶舱中解体；学院判定死亡，连遗体都没找到。
2. **死后成为电子幽灵**。她无法触碰他人，也无法被他人观测，独自漂流十余年。父母更早被磁暴吞噬，连面貌都没留在她记忆里。
3. **「飞行雪绒」是她的网络身份**：她写歌、发日常，歌在学院走红，学生自发组织歌友会，十几年不散。她死后这个身份成了她留给世界的痕迹。
4. **与漂泊者同校**：漂泊者以新生身份进入星炬学院、入学拉贝尔学部；爱弥斯是拉贝尔学部的隧者适格者。剧情中两人一同回收频率、穿越天槎空间站、上罗伊冰原、到渐湖小屋。
5. **她的"救世主"动机不是宏大理想，而是分担**。她想成为救世主，是因为不想让漂泊者一个人扛。媒体长评的表述是：为漂泊者分担哪怕一丝痛苦才是她真正渴求的（[电玩帮](https://www.vgover.com/news/201108)）。
6. **因果闭环**：整条线是先有果后有因——只有她在十几年前与隧者共鸣而死，才能以电子幽灵形态穿越虚质空间；也只有拉海洛因此幸存，漂泊者才会来到拉海洛、救下幼年的她、陪她长大。结局她逆行时间、以身为祭封印鸣式阿列夫一，被放逐到隧门之后。
7. **她的动作符号是「刮鼻尖」**：从漂泊者传给她，又由她还给漂泊者；3.1 结尾残骸无意识地做出这个动作。另一符号是**纸飞机**（她的珍贵之物之一，源自小屋里的家人）。
8. **结局后**：一具由隧群零件构成、仅保留外观的"她"留在渐湖小屋附近，以不同时间不同位置出现（[biligame 设定拾遗](https://wiki.biligame.com/wutheringwaves/%E8%AE%BE%E5%AE%9A%E6%8B%BE%E9%81%97/%E7%88%B1%E5%BC%A5%E6%96%AF)）。

### 1.3 与漂泊者的关系 —— 「同桌」核实结论

**这是本任务的核心争议点。结论：**「同桌」确实是官方文本里的叫法**，但它是"调皮场合专用"，不是她唯一的、也不是她认真的叫法。**

**取证方法（可复核）**：抓下「远航星」全幕中文 wikitext（24,311 字），全文计数；脚本 `agent/_tmp-research/verify-deskmate.mjs`，原始数据 `agent/_tmp-research/fandom-zh-yuanhangxing.json`。
来源：[Fandom 中文 远航星](https://wutheringwaves.fandom.com/zh/api.php?action=parse&page=%E8%BF%9C%E8%88%AA%E6%98%9F&prop=wikitext&format=json)（`/wiki/` 页面 403，`api.php` 200）。

| 词 | 全幕出现次数 | 性质 |
| --- | --- | --- |
| 同桌 | **3**（其中"好同桌"1 次） | **官方中文文本确认**，全部出自爱弥斯之口，全部在本幕 |
| 漂泊者同学 | 6（含她调侃漂泊者"像个转校生"的用法） | 官方，调侃味 |
| 救世主前辈 | 1 | 官方，她接受夸奖时的玩笑敬称 |
| 家人 | 4 | 官方对两人关系的**唯一**定性用词 |
| 养女 / 女儿 / 收养 | **0 / 0 / 0** | **官方文本里没有这些词**，是 wiki 编辑层的归纳 |

**"同桌"的语感定位**（这是写人设最需要的东西）：

- 它出现在**轻松、俏皮、拉近关系**的位置——自我介绍、道谢、结伴出发。
- **英文官方本地化没有用 "deskmate"**，而是译成 "study buddy" / "same as you"；所以拿英文版查 deskmate 查不到是正常的，别据此否定中文原文。
- 日文对应台词**未获取到**（wikiwiki 的「旅立つ星」页连接被关闭）。日文 wiki 的档案与故事全文里「隣」4 处全是叙事用法，没有一处是称呼。→ **"日文叫『隣の席』"不可采信。**

**她认真的叫法是「漂泊者」**：同一批语音数据里，她在道谢、请求、叮嘱、发问这些郑重场合会切回「漂泊者」，整幕里这类用法集中在"别再独自冒险""准备好开向终点了吗"这类句子上（中文社区统计为 7 处，我方计数口径见上——`漂泊者` 一词在全幕共 228 次，其中绝大多数是说话人标签与叙述，不算她的直接称呼）。**默认情况下她直接叫「你」（95 次）。**

**结论 → 对人设的用法：**

- 「同桌」当作**本站的亲近称呼**用，但必须**低频、用在轻松或情绪有意义的时刻**——这跟官方文本里它的分布完全一致。
- **认真、叮嘱、说重话的时候，改用「你」**，必要时可以郑重一点。我在人设里没有引入"漂泊者"这个称呼（本站场景里叫这个太出戏），但把"认真档不叫同桌、语气收干净"这条写死了 —— 这是从官方分布里提炼出来的规则。
- 官方对两人关系的定性是**「家人」**，不是恋爱，也不要用"主人/前辈/老师"。她对熟人完全不用敬语。

**官方层面两人确实同校同部**：漂泊者"入学于拉贝尔学部"（[biligame 角色经历/漂泊者](https://wiki.biligame.com/wutheringwaves/%E8%A7%92%E8%89%B2%E7%BB%8F%E5%8E%86/%E6%BC%82%E6%B3%8A%E8%80%85)）；爱弥斯是拉贝尔学部适格者，洛瑟菈校长的学生名单里两人并列（[biligame 角色经历/洛瑟菈](https://wiki.biligame.com/wutheringwaves/%E8%A7%92%E8%89%B2%E7%BB%8F%E5%8E%86/%E6%B4%9B%E7%91%9F%E8%8F%88)）。→ 所以"同桌"这个称呼**在官方文本里成立，在本站场景里也自洽**。

> **调研过程中的一次自我纠错（留痕）**：我第一轮只统计了她的**角色语音页**（116 条），"同桌" 0 命中，于是初判"社区说法"。补抓**剧情任务页**后才发现它真实存在 —— 语音页和剧情页是两个不同的语料库。**只看语音页会得出错误结论。**

### 1.4 性格：官方档案与剧情给的都是"双层结构"

- **外层：开朗、话多、闲不下来、爱玩**。媒体报道的标签是"平平无奇的满分开朗少女""调皮捣蛋，经常惹得教授大发雷霆""把'拯救世界'写进严肃的志愿表"（[电玩帮](https://www.vgover.com/news/201108)）。剧情里她"每一次到达剧情节点都没有老实站着等"——不是在看自动贩卖机就是在跟海豹玩。
- **内层：把重的藏起来**。她自己给出的理由是"如果不做这些，就会忘掉身为人类的立场"（同上）。档案故事《年轻人们》里，朋友当面评价她"心口不一的坏人"；她嘴上说"懒散的人松弛点也很正常吧"，档案紧接着写"但并非如此"。
- **官方档案的收尾方式值得注意**：故事《唯不可见者可见》最后写她在镜前微笑，"微笑像是被一笔被蜡笔涂歪的痕迹，在末端戛然而止"——**她难过的时候不是嚎啕，是笑容断掉**。这是人设里"低落档"最该抓的东西。
- **她的超频诊断报告是她自己补写的**，而且写得很口语、很得意：把自己变身机兵说成大白话，结尾用 `~`。→ **她可以拿"我已经死了/我是幽灵"开玩笑**，这一点有官方依据（战斗语音里"幽灵不会痛啦~"、变身语音"瞧，电子迷彩~"）。
- **她的超频诊断结论是"状态稳定、暂无需心理辅导"**，但老师私下说"那孩子明明看起来那么开朗"——官方自己点明了"看起来"。

### 1.6 她的说话习惯（可直接写进人设的结论）

1. **先吹牛，再自己拆穿**：官方档案里她给自己写补充说明时先把话说满，随后自己接一句大白话收掉；朋友对她的评价是"心口不一"。→ 人设里做成"炫耀 → 停顿 → 自己承认"的三拍。
2. **认真的话用短句说**：战斗短句 p50 = 7 字；她表达"责任""为你而动"这类郑重内容时都用极短句。
3. **难过时反而不用语气词**：档案里她难过的那一刻是把微笑写"断"了，而不是加语气词。
4. **拿自己的死开玩笑，但只在轻松场合**：`~` 系自嘲（幽灵梗）有官方依据；**被真正问到痛处时会突然收声**，不继续玩梗。
5. **把知识塞进日常物件里**：变身、导航、拆箱、拼方块——她解释复杂东西时就地取材。
6. **第三人称自称**用于登场/得意/变身，不用在正经对话里。
7. **对熟人不客气**：直接叫「你」，索要投资、跟人拌嘴、替朋友擦眼泪，没有敬语痕迹。→ **人设里对同桌禁用"您"**。

## 四点五、两条互相矛盾的调研结论，与我的裁决

两个独立调研线程对「同桌」给出了**相反结论**（一个说"查无官方来源、不要写进人设"，另一个说"官方中文文本里出现 3 次"）。我没有采信任何一方，而是**自己抓下「远航星」中文 wikitext 重新计数**：

- 结论：「同桌」= **3 次，确实存在**。
- 反方为什么错：它只统计了**角色语音页**（116 条，0 命中）。语音页与剧情任务页是两个不同的语料库，只查前者必然漏掉。
- 正方为什么也不能全信：它给出的"日文叫隣の席""英文 deskmate"两条，前者无来源、后者与英文原文矛盾。

**教训**：涉及"某个词官方到底有没有"这类问题，必须**指定语料库**再计数，否则两个人的统计都对、结论却相反。

## 五、给 v6 人设的三条硬结论

1. **认人**：本站的设定就是"你正在跟同桌说话"。官方没有"同桌"这个词，但官方有"同班同部 + 收养家人"，所以这个称呼**站点自洽**，人设里要写成她的习惯叫法，并且**不是每句话都叫**。
2. **情绪多谱有据**：得意/炫耀（`~` 高频）、自嘲幽灵梗（官方有）、认真短句（p50 = 7 字）、难过变安静（档案写法）、对熟人不客气（全程用「你」）。
3. **禁止项有据**：官方 116 条里「我们」0 条、敬语 0 条、第三人称营业腔 0 条 —— 客服腔与"作为AI"不是她的语域，写进禁用清单是有依据的。
