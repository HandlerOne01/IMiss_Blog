## Q7　`指针和引用有什么区别？`

**v1-a** (1.7s)

```
指针是变量，存的是地址，可以为空，也能改指向。引用是别名，绑上就不能换，也不能为空。

用的时候：引用更安全，指针更灵活。想改指向、想判空，用指针；只是给变量起个名字，用引用。

站里《指针，引用与const的复杂关系》讲这个，约 120 字，但全是代码示例。
/posts/cpp/zhizhen-yinyongyu-const-defuzaguanxi/
```

**v1-b** (1.8s)

```
指针是变量，存的是地址，可以为空，也能改指向。引用是别名，绑上就不能换，也不能为空。

用的时候：引用更安全，指针更灵活。想改指向、想判空，用指针；只是给变量起个名字，用引用。

站里《指针，引用与const的复杂关系》讲这个，约 120 字，但全是代码示例。
/posts/cpp/zhizhen-yinyongyu-const-defuzaguanxi/
```

**v2-a** (2.5s)

```
指针是一个变量，存的是地址；引用是别名，从生下来就绑死在一个对象上，不能改绑。

几个常被问到的点：
- 指针可以为空，引用不行。
- 指针能重新指向别人，引用不能。
- 指针有自己的一块内存，引用通常不占。

站里《指针，引用与const的复杂关系》讲的就是这个，不过它字少、全是代码，得对着敲一遍才看得进去。
/posts/cpp/zhizhen-yinyongyu-const-defuzaguanxi/

想从更基础的看，《指针》那篇约 1200 字，先看它也行。
```

**v2-b** (1.8s)

```
指针是变量，存的是地址。引用是别名，从生下来就绑着谁，改不了。

几个常被问到的点：

- 指针可以为空，引用不行。所以「这个参数不能为空」的时候用引用。
- 指针能重新指向别人，引用一辈子只认一个。
- 指针有自己的大小，引用没有——`sizeof(引用)` 量的是它绑的那个东西。
- 引用底层多半也是指针实现的，但那是实现，不是语义。

站里有一篇正好讲这个：

《指针，引用与const的复杂关系》· C/C++ · 约 120 字
/posts/cpp/zhizhen-yinyongyu-const-defuzaguanxi/

字少，但整篇都是代码示例，别被那个数字骗了。
```
