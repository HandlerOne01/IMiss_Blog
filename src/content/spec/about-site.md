# 关于本站

这里是 **HandlerOne** 的个人博客，主要放技术笔记。

站内的配色、插画和右下角的桌宠都取自《鸣潮》的爱弥斯。

## 站里有什么

- **文章** —— 138 篇，分 12 个分类：C/C++、Linux 系统、Linux 网络、算法、MySQL、STL、C++11、八股文、AI 应用、项目梳理、项目实战、本站维护；另有 42 个标签、2 个系列。
- **学习路线** —— 把站内文章按 8 条主线排成一条有先后的路径，共 141 个停靠点，每条主线标了难度和大概耗时（合计约 70 小时）。
- **爱弥斯桌宠** —— 右下角那只。她读过站里的文章，可以让她推荐几篇，或者介绍某一篇。
- **项目** —— 四个自己写的项目，正文和实现说明都在站内：《仿 muduo 实现的高并发服务器》《基于正倒排索引的 Boost 搜索引擎》《基于 LangChain / LangGraph 个人博客智能助手》《vibecoding IMiss_Blog个人博客》。
- **相册** —— 一个相册「本站图片」，8 张原图。
- **书签导航** —— 6 组共 39 个平时会用的站点。
- **动态 / 音乐** —— 一条短动态；歌单是本地文件，侧栏和导航上各有一个入口。
- **关于我** —— 联系方式（邮箱、微信）和几个游戏 ID。

## 你可以这样逛

### 找文章

1. 顶部 **「文章」** 下拉里有四种找法：**归档**（按时间）、**分类**、**标签**、**系列**；
2. 右上角的**放大镜**是站内搜索，中文也能搜；
3. 首页往下是最新文章列表，侧栏有分类、标签、最新动态和站点统计；
4. 长文章右侧有**目录**，可以直接跳到某一节（手机上是一个浮动按钮）。

### 跟爱弥斯说话

- 电脑上**右键**点她、手机上**长按**她 → 选「和爱弥斯聊天」；
- 可以直接说：「推荐几篇讲 Linux 的文章」「介绍一下那篇讲 HTTP 的」「你是谁」；
- 她的回答都来自站内文章，取不到数据时会直说，不会编；
- 另外：可以拖着她走、单击让她跳一下；右键菜单里能让她「落下去 / 飘起来」，也能「缩小」成很小一只（双击叫回来）。

### 换个样子看

- 右上角的**调色盘**面板可以改主题色、字号这些；
- 壁纸是动态的，有**横幅、全屏、透明覆盖**三种模式；换下一张：电脑上点空白处，手机上左右滑。
- 进站看到哪一张**跟着北京时间走**：深夜是星夜、清晨是起床，白天按点在洗手台、湖畔、窗边、塔罗之间轮换。

### 手机上

- **长按 = 电脑上的右键**，桌宠的菜单一样能开；
- 横幅会重新取景，保证人物在画面里；
- 其他操作和电脑一致：文章、路线、搜索都能正常用。

## 这个站是怎么搭的

静态生成用 **Astro**，交互部件用 Svelte，样式是 Tailwind。每篇文章就是一个 Markdown 文件，构建时统一编译；图片、壁纸、歌单都是本地素材。

桌宠的对话不直接打后端，中间过一层自己写的**同源网关**，限流和长度校验都落在那一层。

想自己折腾这个站，可以看《[本站使用与维护手册](/posts/project/boke-shiyong-yu-weihu-shouce/)》。
