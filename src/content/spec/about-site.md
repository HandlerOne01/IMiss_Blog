# 关于本站

我是 **IMiss**。这里是**我自己的技术笔记仓库**，也是我练手的地方。

因为喜欢《鸣潮》里的爱弥斯，这个站的样子、右下角那只桌宠、还有她说话的口气，都是照着她来的。

## 站里有什么

- **文章** —— C/C++、Linux、网络、MySQL、算法、AI 应用这些方向的笔记，按分类归档。写的时候尽量按「过几个月还能看懂、还能查回来」的标准来，不是把概念抄一遍。
- **学习路线** —— 把站里的笔记按 8 条主线排成一条有先后的路径（每条主线标了难度和大概要花多少小时），免得像我一样东看一篇、西看一篇。
- **爱弥斯桌宠** —— 右下角那只。她能聊天，而且**真的读过这个站**。
- **项目 / 相册 / 书签导航 / 动态** —— 我做过的东西、随手记的东西和常去的站点。
- **音乐播放器** —— 侧栏和导航上各有一个入口，歌单是我自己放的。

## 你可以这样逛

### 想自己找文章

1. 顶部 **「文章」** 下拉里有四种找法：**归档**（按时间）、**分类**、**标签**、**系列**；
2. 右上角的**放大镜**是站内搜索，中文也能搜；
3. 首页往下就是最新文章列表，侧栏有分类、标签、最新动态和站点统计；
4. 长文章右侧有**目录**，可以直接跳到某一节（手机上是一个浮动按钮）；
5. 如果不知道从哪看起，去 **「学习路线」** —— 按主线顺序读，比一篇篇翻省事。

### 跟爱弥斯说话（我觉得最好玩的部分）

**电脑上右键点她，手机上长按她**，菜单里选「和爱弥斯聊天」，然后随便说点什么，比如：

- 「**推荐几篇讲 Linux 的文章**」——她会从站里挑几篇给你，带标题；
- 「**介绍一下那篇讲 HTTP 的**」——点名一篇，她会去翻出来讲给你听；
- 「我是谁」「你是谁」——她有自己的回答方式，试试就知道了。

她背后接的是一个真的 Agent（LangGraph + DeepSeek），**只依据站内检索到的内容说话**：查不到就直说查不到，不会替你编一个不存在的链接。后端没开着的时候，她会退回几句本地台词，不会甩你一脸报错。

除了聊天，菜单里还有几件事可以做：「**落下去 / 飘起来**」让她落到页面底部或者飘回半空，「**缩小**」把她变成很小一只（双击就能叫回来）。你也可以直接**拖着她走**，或者点她一下——她会跳一下。

### 换个样子看

右上角的**调色盘**（显示设置面板）里可以改：主题色相、文章列表布局、卡片边框、壁纸模式（横幅 / 全屏 / 透明覆盖）、水波纹、樱花、标题打字机等。

壁纸是**动态的**：首页横幅上是她，全屏壁纸会铺满整屏，也可以切成透明覆盖只留一层淡淡的底。想换下一张：电脑上**点空白处**、手机上**左右滑**都行。

### 手机上

- 横幅比电脑矮一些，取景会跟着重新算一遍，保证人物（尤其是脸）在画面里；
- **长按 = 电脑上的右键**，桌宠的菜单一样能开；
- 其他操作跟电脑一致，文章、路线、搜索都能正常用。

## 现在还没有的东西

- **评论区**还在选型，所以站上暂时没有留言入口。想找我聊，直接找爱弥斯，或者去导航「链接」里那几条（Gitee / GitHub / CSDN / 洛谷）找我；
- **轻小说**和**番剧**两页还在接数据源，现在打开是占位卡片；
- **「关于我」**那一页还空着 —— 等我想清楚怎么写自己（笑）。

## 这个站是怎么搭的

静态生成用 **Astro**，交互部件用 Svelte，样式是 Tailwind。桌宠的对话不直接打后端，中间过一层自己写的**同源网关**，限流和长度校验都落在那一层。

内容这边，每篇文章就是一个 Markdown 文件，构建时统一编译；图片、壁纸、歌单也都是本地素材，不依赖第三方图床。这套流程我自己写了一份《[本站使用与维护手册](/posts/project/boke-shiyong-yu-weihu-shouce/)》，有兴趣折腾博客的话可以看那篇。
