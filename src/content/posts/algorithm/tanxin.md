# 贪心：排序推公式
- **思路**
1. 猜一个排序依据（比如按重量、按 deadline、按权值差等）
2. 任取相邻两项 i, j 假设顺序错了，写出交换前/后只与这两头有关的代价/收益表达式
3. 令“交换后更优”得不等式，化简成key(i) < key(j) 或 key(i) > key(j)这个 key 就是 sort 的排序键
4. 全局按 key 排一遍序即可，Greedy 正确性由“相邻交换不影响其余部分”保证

- **经典例题**

| 题目    | 相邻交换不等式                     | 排序键                          | 备注                   |
| ----- | --------------------------- | ---------------------------- | -------------------- |
| 奶牛玩杂技 | (W+wi)−sj < (W+wj)−si       | i+si < wj+sj 即 wi−si < wj−sj | 按 wi+si 升序排，最小化最大压扁值 |
| 排队接水  | i 在前 j 在后总等待 < j 在前 i 在后总等待 | ti < tj                      | 按时间升序，最小化总等待时间       |
| 活动安排  | 结束早的先选                      | end<endj                     | 按结束时间升序，最大化场次        |
- 模板代码（奶牛玩杂技）
```cpp
struct Cow { int w, s; };
bool cmp(const Cow& a, const Cow& b) {
    return (a.w + a.s) < (b.w + b.s);   // 推出来的排序键
}
sort(cows, cows + n, cmp);

```
- 注意
1. 能否只比较相邻两项？
2. 交换后其余部分代价是否不变
3. 不等式能否化简成只与单项数据有关的键？
4. 直接sort一遍得到全局最优
