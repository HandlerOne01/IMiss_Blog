# 一维前缀和
 1. 核心思想
  - 预处理：提前计算并储存数组的累加和，空间换时间；
  - 查询优化：`O(n)->O(1)`;
1. 构建前缀和数组
- 原数组`a[i]`,前缀和数组`f[i]`;
```cpp
  f[0] = 0；
  f[i] = f[i-1] + a[i]；   (1 ≤ i ≤n)
```
3. 区间和查询
- 查询闭区间`[l,r]`的和
```cpp
  sum(l, r) = f[r] - f[l-1]；
```
# 二维前缀和

1. 核心思想
- 扩展一维思想到矩阵，快速求子矩阵的和
2. 构建前缀和矩阵
- 原矩阵`a[m][n]`，前缀和矩阵`f[i][j]`（（1，1）到（i，j）矩阵中所有元素和）;
```cpp
  f[0][j] = f[i][0] = 0;   (边界置0)
  f[i][j] = f[i-1][j] + f[i][j-1] - f[i-1][j-1] + a[i][j]；
```
3. 子矩阵查询
- 查询左上角（x1,y1）右下角（x2,y2）的子矩阵和；
```cpp
  sum = f[x2][y2] - f[x1-1][y2] - f[x2][y1-1] + f[x1-1][y1-1]；
```
几何意义：
全区域-上侧区域-左侧区域+重叠减去的部分

4. 时间复杂度
- 预处理O(nm);
- 单次查询O（1）；
